# NetworkGuard — مشروع أندرويد

**إعداد:** علي ولاء جاسم — علي كرار زيدان

## ماذا يفعل؟
- واجهة عربية لعرض نتيجة فحص الشبكة المحلية.
- يحاول قراءة عنوان Wi‑Fi للهاتف لتحديد نطاق /24 تلقائياً، مع نطاق احتياطي `192.168.1.x` إذا لم يتوفر العنوان.
- فحص متوازٍ لعناوين IP وعرض العناوين التي تستجيب لاختبار الاتصال.
- تصنيف يدوي مؤقت للأجهزة على أنها موثوقة أو غير مصنّفة.

## حدود مهمة
هذا إصدار أولي قابل للبناء، وليس أداة مراقبة احترافية معتمدة. اكتشاف الأجهزة ليس مضموناً؛ بعض الأجهزة والراوترات تمنع ICMP/ping. تصنيف «غير مصنّف» لا يعني وجود اختراق. التطبيق لا يعرض MAC بشكل موثوق، ولا يحظر أجهزة، ولا يغيّر إعدادات الراوتر. افحص شبكة تملكها أو لديك إذن بفحصها فقط.

## بناء APK عبر GitHub من الهاتف
1. أنشئ مستودعاً جديداً على GitHub وارفع **محتويات** هذا المجلد إليه (وليس ملف ZIP فقط).
2. افتح تبويب **Actions** في المستودع وفعّل Actions إذا طُلب ذلك.
3. اختر **Build NetworkGuard APK** ثم **Run workflow**.
4. بعد اكتمال التشغيل، افتح صفحة التشغيل الناجح، وانزل إلى **Artifacts** ونزّل `NetworkGuard-debug-apk`.
5. فك ضغط الملف المحمّل وافتح `app-debug.apk` على هاتف أندرويد. قد تحتاج السماح بالتثبيت من هذا المصدر.

ملف APK الناتج نسخة Debug للتجربة، غير منشورة على متجر Play. هذا المستودع لا يحتوي أسرار توقيع أو مفاتيح خاصة.
